# CredChain

Decentralized credential platform with Nuxt 4 frontend and Hardhat smart contracts.

## Workspaces
- apps/web: Nuxt 4 web app with Material Design 3 theme and responsive UI
- contracts: Hardhat project for ERC721 + ERC5192 credential contracts
- packages/shared: shared types and crypto metadata helpers

## Quick start
1. Install dependencies:
   npm install
2. Start local chain:
   npm run dev:chain
3. In another terminal, run web app:
   npm run dev:web
